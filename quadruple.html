Quadruple Sudoku

An 8×8 grid using Double Sudoku’s outlined regions. Each row, column and region contains exactly four 0s and four 1s.

Generating a uniquely solvable puzzle…

Choose a number, then tap a blank cell. Or focus a cell and type 0 and 1; use Backspace to erase. Notes are optional pencil marks. Red cells mean a number appears more than four times in a row, column or region.

Single-cell mode stops when no clue can be removed. Dual-cell mode removes 180° rotationally opposite pairs only and stops when no opposite pair can be removed. A single removable clue may remain.

Use the same eight outlined regions as Double Sudoku. Each row, column and region contains four 0s and four 1s. Dots represent blanks; 0 is always a real digit.

Completed counts

If a unit already has four 0s, all its empty cells must be 1. The reverse also holds.

Single candidates and forced copies

Check the row, column and region of each empty cell. If only one digit fits, place it. If a unit needs two more 1s and only two cells allow 1, fill both.

Contradiction checks

When basic counts stall, the walkthrough can test both values with an exact solver. If one value has no valid completion, the other is forced. These steps are explicitly labelled search-assisted.
